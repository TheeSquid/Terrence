# Terrence

Terrence is a personal productivity-management Android app built around a mascot-driven accountability system.

## Project status

Milestone 6 is complete. This repository is being established as the canonical source-control home for Terrence.

## Android compatibility

- Minimum Android version: Android 10 / API 29
- Current target: Android 17 / API 37
- Primary validation device: Google Pixel 8 Pro
- Secondary validation device: Google Pixel 9

## Repository conventions

Source code and project documentation belong in this repository. Signed APKs should be distributed through GitHub Releases rather than committed into the source tree.

Android signing keys, passwords, local machine configuration, and other secrets must never be committed.

## Releases

Stable builds will be versioned and published as GitHub Releases with the matching signed APK and release notes.
